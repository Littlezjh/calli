统计放在 数据 状态 主题

桌面

点读数看明细，点右上角的轨迹按钮打开这一轮的时间线。悬停时间条看具体时刻，点时间条或下面的行展开详情。

手机

读数和明细的点法和桌面一样，明细从底部弹出。轨迹铺满整屏。

说明

  • 右上角读数与输入框下方。右上角不占输入区，读数挨着轨迹按钮；但手机顶栏放不下读数，只能放进轨迹页顶部。输入框下方和 DSH 一样一眼能看到，手机上多占一行，约 26px。
  • 右上角卡片。学 Codex：顶栏只多一个按钮，读数、Token 明细和最近一轮的迷你时间线都在卡片里，失败的步骤直接列出来，「查看全部」打开完整轨迹。卡片在桌面上一直开着，直到再点按钮，盖在对话右上方；手机上从顶栏下拉，点别处收起。
  • tok/s 口径。输出 token 除以生成时间，不含等待首个 token 的时间。pi、zcode 用原生上报的耗时；Claude、Codex 不报，由 hub 用收到第一段和最后一段输出的时间来算，读数前加「约」。
  • 缓存命中。缓存读取 ÷（未缓存输入 + 缓存读取 + 缓存写入）。没有缓存数据就不显示这一项，不显示 0。
  • 按需加载。首屏只取汇总；点开读数才取明细，打开轨迹才读这一轮的步骤。
  • 数字都是示例数据。
