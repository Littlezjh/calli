实现要点
  • 标签存在 daemon 的 tags / thread_tags 里，不写进标题；现在标题开头的 [标签]、【标签】 只作为迁移来源，迁移后不再用。
  • 看板筛选：标签之间是「或」，和项目、实例、是否定时之间是「且」；标签计数按全部未归档线程算，不随其他筛选变化。
  • 卡片最多显示 2 个标签，多的显示 +N；加标签的选择器最多 20 个字，同名不区分大小写。
  • 颜色只有普通和强调两档，在「配置 → 标签」里改；删除标签会同时解除关联。
  • 手机：标签条横向滚动，选择器是底部面板；卡片上的 ⋯ 一直显示，桌面悬停才出现。
