# 设计图

界面的目标样子。由图像模型按文字说明生成，用来对齐方向，不是像素级标准。图里的线程名、目录名都是虚构的。

| 文件 | 画面 |
|---|---|
| `desktop.jpg` | 桌面主界面：分组的侧边栏、带图片和改动卡片的对话、输入框 |
| `menu.jpg` | 线程右键菜单（含"移到分区"子菜单）和已归档面板 |
| `mobile.jpg` | 手机三屏：线程列表、对话与审批卡片、导入历史 |

## 和实现不一样的地方

- 侧边栏每行没有文件图标，线程前面只留文字，更安静。
- 图里的"标记为未读"和"从此处分支"还没做，见 `../TODO.md`。
- 生成的图里偶尔有错字或对不齐的行号，以代码为准。

## 视觉规则

- 暖色纸感：背景米白，文字近黑，卡片白色，1px 细边框。
- 主操作是深色，不用蓝色。彩色只表示状态：绿色运行中，橙色警告或完全访问，红色危险。
- 圆角 14–22px，阴影柔和，线性图标，留白多。

具体数值在 `packages/web/src/styles.css` 顶部的变量里。
