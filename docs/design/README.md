# 设计图

界面的目标样子。由图像模型按文字说明生成，用来对齐方向，不是像素级标准。图里的线程名、目录名都是虚构的。

| 文件 | 画面 |
|---|---|
| `desktop.jpg` | 桌面主界面：分组的侧边栏、带图片和改动卡片的对话、输入框 |
| `menu.jpg` | 线程右键菜单（含"移到分区"子菜单）和已归档面板 |
| `mobile.jpg` | 手机三屏：线程列表、对话与审批卡片、导入历史 |

## 和实现不一样的地方

- 侧边栏每行没有文件图标，线程前面只留文字，更安静。
- 桌面侧边栏没有照 `desktop.jpg`，而是和手机同一套版式：搜索收在圆形按钮后面，「新线程」和「配置」悬浮在底部，分组头是加粗标题，不带文件夹图标。已归档、导入历史、退出、外观都在「配置」里。
- 已有线程的输入框上面没有 agent 和目录那一条，它们在顶栏标题下面。那一条只在新线程时出现。
- 线程行右边是 agent 的标志，不是图里的名字小标签。标志是单色的，不带品牌色。
- 图里的"标记为未读"和"从此处分支"还没做，见 `../TODO.md`。
- 生成的图里偶尔有错字或对不齐的行号，以代码为准。

## 视觉规则

- 暖色纸感：背景米白，文字近黑，卡片白色，1px 细边框。
- 主操作是深色，不用蓝色。彩色只表示状态：绿色运行中，橙色警告或完全访问，红色危险。
- 圆角 14–22px，阴影柔和，线性图标，留白多。
- 上面说的是默认主题「纸」。「配置 → 外观」里还有另外几套主题，各自有亮暗两版，强调色可以带颜色；状态色不跟主题走。

具体数值在 `packages/web/src/styles.css` 顶部的变量里。新加一套主题：在那里写它亮、暗各六个颜色，再到 `src/appearance.ts` 的 `PALETTES` 里加上名字。
