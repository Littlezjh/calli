# Calli 应用图标

采用 B「大钳小钳」螃蟹方案：圆润身体、一大一小的双钳、短眼柄与简化的腿。蓝色 #2F5BD3，浅蓝底 #EEF3FC。品牌名称为 Calli，侧栏使用螃蟹图标与名称并排展示。

## 文件与用途

- `packages/web/public/limi-icon.svg`：完整矢量源文件。
- `packages/web/public/limi-icon.png`：1024 × 1024，安装应用与 README。
- `packages/web/public/apple-touch-icon.png`：180 × 180，Apple 主屏图标。
- `packages/web/public/favicon.svg`、`favicon-32.png`：小尺寸简化版，移除白色瞳孔以减少噪点。
- `packages/site/public/limi-icon.png`：180 × 180，官网品牌展示。

图标为手工矢量设计，无生图提示词。PNG 从矢量稿渲染导出。网页及应用清单使用版本化资源地址；已安装的 Chrome 应用可能需要接受浏览器提供的图标更新。
