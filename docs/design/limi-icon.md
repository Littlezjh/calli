- 正式图标：`packages/web/public/limi-icon.png`，1254 × 1254 PNG。
- 使用位置：浏览器标签页、Apple 主屏幕图标、README 品牌展示。
- 生成方式：内置 image_gen，以第二版截图为参考重新设计；采用用户选定的第三版原图。
- 配色方向：浅薄荷绿 #DCEEE5、奶油白 #FFF9ED、橙色 #F6A45D、可可棕 #604739。
- 小尺寸优先保留圆润轮廓、两根短触角与表情。
