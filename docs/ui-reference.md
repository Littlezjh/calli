# UI 参考：Codex 手机端（文字描述）

> 本文档只描述结构与交互，不含截图。参考截图属于内部材料，不入库。
> 描述基于 18 张手机截图（iOS，白色主题）。

## 线程列表页

- 顶部：左侧圆形菜单按钮；中间标题（"Codex ▾"，可切换）；右侧圆形搜索按钮。
- 顶部环境 tab：全部 / 云端 / 某台本机（带绿点表示在线）。
- 列表分组：置顶、今天、昨天、过去 7 天；也可切换为按项目分组。
- 每行：标题；下方灰色元信息（主机图标 + 项目名）。
- 底部悬浮胶囊输入框："向 Codex 提问"，右侧麦克风与发送。
- 右上菜单：优先级、按项目 / 按时间排序、已归档任务、添加连接、设置、剩余用量。

## 线程对话页

- 顶部：返回按钮；标题；副标题"项目 • 主机"；右侧编辑与更多按钮。
- 用户消息：蓝色气泡，靠右。
- 助手消息：无气泡，左对齐，支持 Markdown 表格与代码块。
- 工作过程：折叠行"用时 X 分钟 ›"，展开后是工具行。
  - 工具行：灰字 + 小图标（浏览文件、搜索、运行命令、读取文件）。
  - 点开可看 Shell 命令与输出代码块，底部有"成功"状态。
- 文件改动卡片："已更改 N 个文件  +A −B"，展开列出每个文件的增删行数。
- 回答下方操作：复制、点赞、点踩、分享，并显示耗时。
- 底部输入区：左侧 + 号、权限盾牌图标（橙色）；右侧语音与发送。
- 输入框上方选择栏：主机 / 项目 / 本地或云端 / 分支。
- 选中文字后出现浮层：添加到聊天、拷贝、在侧边聊天中提问、更多。
- 批注：输入框上方出现"N 条批注 ×"标签，随下一条消息提交。

## 视觉基调

- 背景白色，次要文字灰色，强调色蓝色（用户气泡、发送按钮）。
- 系统字体，圆角胶囊控件，轻阴影。
- 整体留白较多，信息密度低。
