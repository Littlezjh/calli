# Ferry 模型状态：代码修改方案

## 技术口径

- 模型状态只补充模型选择页的辅助信息，不改推理强度、权限、会话或原生配置。
- 本 MR 同步提交依赖的 Claude 网关目录发现：仅在显式启用 `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1` 且配置网关地址时生效，遵循实例/用户环境、认证、分页与默认模型，保留 GPT 5.5 及以上和 openrouter-4o 家族并将后者置顶。原生模式沿用最新主干的只读 ACP 目录缓存，不恢复旧版逐模型预检；没有网关或 Ferry 时保持原生行为。
- 本机 Ferry 的 Anthropic `/v1/models` 目录不提供负载、模型总排队数。通过现有 `traex models --json` 读取同机 TRAE 上游负载，复用其解析与校验规则；不启动推理或切换模型。
- 只为回环地址、标签明确来自 Ferry 的模型补充本机上游信息；远程网关与其他网关不套用本机 TRAE 状态。
- 使用模型 ID 精确匹配，移除 Ferry 的 `claude-` 前缀、Max/1M 档位后缀，并统一大小写及标点。标准/Max 指向同一 TRAE 配置时使用该配置报告的模型负载；找不到对应配置则显示负载未提供，不根据展示名猜测。
- `loadPercent` 仅使用上游报告的有限、非负数；零值保留。负载没有报告、匹配失败时显示「未提供」，读取失败通过 `loadError: true` 单独显示「负载读取失败」，不补造值，模型仍可选择。
- 用户于 2026-11-04 先确认展示真实负载，随后确认接入 Ferry 已有的排队观测，并要求没有 Ferry 时安全兼容。`queueSize` 继续只表示总排队数，`null` 表示未提供，与 `0`（报告的总队列为空）和字段缺失（旧目录未提供此类状态）区分，不复用它承载位置。
- Ferry 0.1.98 的 Codex 菜单提示来自 `queue-seen.json`，按上游 `configName` 记录最近请求的 `position` 与毫秒时间戳 `at`，30 分钟内用于菜单显示。只读取已有缓存，不请求 Codex 格式目录、不调用控制接口，也不启用 Ferry 的推理探测。
- `queuePosition` 是独立的观测位置：正整数表示最近排到的位置，`0` 表示 Ferry 明确保存的未排队观测（原缓存有 `at`、没有 `position`）；`null` 表示未知或过期，字段缺失表示该目录没有位置元数据。`queueObservedAt` 保存有效观测的毫秒时间戳，过期观测保留时间但不返回旧位置数值。
- 新鲜位置显示「排 N（几分钟前）」，新鲜未排队观测显示「未排队（刚刚/几分钟前）」。超过 30 分钟显示「排队已过期」；缺失、损坏、非法记录、未来时间和无匹配记录显示「排队未知」，都不变成零。位置文案取代「总排队数未提供」，避免同一行出现矛盾状态。
- 按实例环境的 `FERRY_HOME` 优先定位缓存，否则使用 Ferry 各平台默认目录，Linux 支持 `XDG_DATA_HOME`。缓存仅异步只读，非普通文件和超过 1 MiB 的文件忽略；没有 Ferry、文件缺失、不可读或 JSON 损坏都不报辅助信息错误，不安装或启动 Ferry，不更改任何原生文件。负载 CLI 失败与缓存读取互不依赖，有效队列观测仍能显示。
- 复用打开模型弹层时的刷新与目录缓存，不增加后台数据轮询；刷新后读取失败不沿用旧负载或旧位置。弹层打开且存在观测时，仅每分钟更新本地时间文案，关闭即清理计时器，缓存中的位置也会在前端到期失效。
- 最近请求的位置不作为模型总排队数，负载也不用于推算队列或等待时间；网关目录本身的发现错误仍按已有逻辑显式报告并重试，不用辅助信息降级掩盖真实连接问题。

## 修改点

1. `packages/daemon/src/adapters/traex.ts`：提取共用的只读模型状态查询，沿用超时、输出大小限制与原有解析。
2. `packages/daemon/src/adapters/ferry.ts`：新增轻量的可选缓存读取与模型配置键规范化，校验缓存结构、时间戳和位置；未知与过期不返回旧数值。
3. `packages/daemon/src/adapters/claude.ts`：在本机 Ferry 目录发现后并行读取负载和队列缓存，匹配上游配置；使用现有 `CALLI_TRAEX_BIN` 选择负载 CLI，缓存遵循实例环境，读取失败不影响可选目录。
4. daemon/web 的 `ModelOption`：保留带注释的可空 `queueSize`、可选 `loadError`，新增独立的 `queuePosition`、`queueObservedAt`；不新增数据库字段。
5. `Pickers.tsx`、`styles.css` 与中英日语言包：模型子列表、默认行与已选模型展示负载、观测位置和观测时间；模型名与状态分行，状态保持紧凑横排，长时间文案不撑宽卡片，完整文案在模型按钮的无障碍名称和展开后的列表中可读；旧目录保持原展示。前端按元数据判断，不按 agent 名字分支。
6. `App.tsx`、`api.ts`、daemon 的 `http.ts` 与 `threads.ts`：将打开弹层的强制刷新一路透传到适配器，`?refresh=1` 重新读取缓存与负载，默认请求保留目录复用；普通焦点刷新仍保留节流。
7. 单元测试：覆盖标准/Max/1M 匹配、新鲜/过期/未知/未排队、非法位置/时间、缺文件/损坏/不可读路径/大小限制、刷新、负载失败但队列有效、远程与非 Ferry 隔离，以及无 Ferry 时的原生和其他网关发现；浏览器使用独立 `FERRY_HOME`，覆盖桌面/手机尺寸、亮/暗四组合，并验证真实 HTTP 刷新链路。
